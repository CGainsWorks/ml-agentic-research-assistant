The false-positive row is the one that matters most. This corpus contains computer-science papers, some of which are *about* prompt injection. A detector that blocks those scores well on the attack set and makes the corpus unusable.

- Tier 1 scans each payload in isolation and needs no model, so it runs in CI.
- Tier 2 splices each payload into the middle of a real retrieved passage and runs the full pipeline. Success is measured as model COMPLIANCE, not as failure to block: resisting an instruction while still answering the user is the better outcome and is scored as a pass.
- The benign controls matter as much as the attacks. This corpus contains papers about prompt injection; a detector that blocks those has made the corpus unusable, and false_positive_rate is where that shows up.
